# Compra (Filippi)

PWA de estoque doméstico e lista de compras — React + TypeScript + Tailwind + Firebase Realtime Database.

## App

- Estoque por categorias (limpeza, higiene, cozinha, lavanderia, outros)
- Estoque mínimo e alertas de reposição
- Geração e edição de listas de compra
- Sync em tempo real no Firebase (`filippi-82725`)
- Deploy automático no GitHub Pages

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build / Pages

```bash
npm run build:pages
```
